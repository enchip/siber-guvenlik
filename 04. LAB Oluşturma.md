# LAB Oluşturma
Siber güvenlik testleri yapılırken mutlaka bu iş için ayrılmış, internetten ve üretim ağlarından yalıtılmış ortamlar kullanılmalıdır. Gerçek sistemler üzerinde yalnızca yazılı izin ile test yapılabilir.

# İşletim Sistemleri
- Kali Linux (64 Bit, sanal makine imajı)
- Parrot Security OS (İsteğe bağlı)
- Metasploitable 2 / 3 (Kasıtlı olarak zafiyetli bırakılmış hedef sistem)
- Windows 10 / 11 istemci (Değerlendirme sürümleri)
- Windows Server 2019 / 2022 / 2025 (Active Directory LAB'ı için, değerlendirme sürümleri)
- Ubuntu Server (Web ve konteyner LAB'ları için)

# Sanallaştırma ve Konteyner Araçları
- VMware Workstation Pro (Kişisel kullanım için ücretsiz)
- VirtualBox
- Proxmox VE (İsteğe bağlı, ev LAB'ı için)
- Docker (Zafiyetli uygulamaları hızlıca ayağa kaldırmak için)

# Zafiyetli Uygulamalar ve LAB Ortamları
- DVWA, OWASP Juice Shop, OWASP WebGoat
- GOAD (Game of Active Directory)
- OWASP crAPI (API güvenliği)
- flAWS, CloudGoat (Bulut güvenliği)

# Ağ Yapılandırması
- Saldırgan ve hedef makineleri "Yalnızca Ana Makine (Host-Only)" veya "Dahili Ağ (Internal Network)" modunda çalıştırın.
- Zafiyetli makineleri doğrudan internete açmayın.
- Denemelerden önce anlık görüntü (Snapshot) alın.
